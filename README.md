# Next Level notes (Vercel edition)

Digital notes / e-book store. Express + MongoDB Atlas + Vercel Blob, deployed on Vercel.
Live: https://notes.nxtlevellive.xyz

## Architecture
- `public/` served by the Vercel CDN (index, admin, 404). `vercel.json` adds security headers and rewrites (`/admin` -> `/admin.html`, SPA fallback).
- `index.js` exports the Express app from `backend/server.js` (one Vercel Function). It handles `/api/*` and `/config.js`.
- MongoDB connection is cached across warm invocations (`backend/lib/db.js`). Indexes are created idempotently once per instance (`npm run indexes` also works).
- Product images -> **public** Vercel Blob store (server upload, max 2 MB).
- Paid ZIPs -> **private** Vercel Blob store. Admin uploads go browser -> Blob directly (bypasses the 4.5 MB Function body limit). Customers download through `/api/orders/:orderId/download/:productId`, which checks login + paid order and streams the file.
- Rate limits for sensitive routes are stored in MongoDB (`rate_limits`, TTL) so they hold across instances. Admin login lockout is also in MongoDB.
- `GET /api/cron/cleanup` (Vercel Cron, daily) removes orphan files. Protected by `CRON_SECRET`.
- Admin-only self-check: `GET /api/admin/diagnostics` (after logging in at `/admin`).

## Commands
```
npm install
npm run build:client   # bundles @vercel/blob/client -> public/vendor/blob-client.js (commit it)
npm run indexes        # optional: create MongoDB indexes manually
npm start              # local run on http://127.0.0.1:3000 (needs .env and Blob tokens)
```

## Notes
- `public/config.js` was removed on purpose: `/config.js` is generated by the API so the Google Client ID comes from env.
- Do not put Cloudflare's proxy (orange cloud) in front of Vercel; rate limiting relies on the real visitor IP.
- The old GitHub Pages workflow was removed; this app needs its API.
